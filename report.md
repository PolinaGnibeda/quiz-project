## 6. Использованные команды Git

| Команда         | Назначение                                                                  |
|-----------------|-----------------------------------------------------------------------------|
| git --version   | Проверка установленной версии Git на компьютере.                            |
| git config      | Настройка параметров Git (имя пользователя, email, ветка по умолчанию).     |
| git clone       | Клонирование удаленного репозитория с GitHub на локальный компьютер.        |
| git status      | Просмотр текущего состояния рабочей директории и индекса.                   |
| git add         | Добавление изменений или новых файлов в индекс перед коммитом.              |
| git commit      | Фиксация (сохранение) подготовленных изменений в истории репозитория.       |
| git push        | Отправка локальных коммитов и веток в удаленный репозиторий на GitHub.      |
| git log         | Просмотр истории коммитов (в виде списка или графа).                        |
| git checkout    | Переключение между ветками или отмена локальных изменений.                  |
| git checkout -b | Создание новой ветки и автоматическое переключение на неё.                  |
| git branch      | Просмотр списка веток в репозитории.                                        |
| git pull        | Получение актуальных изменений из удаленного репозитория и их слияние.      |
| git branch -d   | Удаление локальной ветки после её успешного слияния.                        |
| git merge       | Слияние (объединение) указанной ветки с текущей активной веткой.            |
| git rm          | Удаление файлов из рабочей директории и из-под отслеживания Git.            |
| git tag         | Создание метки (тега) для обозначения версий и релизов проекта.             |
