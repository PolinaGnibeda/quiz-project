# quiz-project
Командный тест по Git — практическая работа
## Состав команды
- Студент A — Team Lead и координатор PR (вопросы 1–2)
- Студент B — Разработчик (вопросы 3–4)
- Студент C — QA (вопросы 5–6, отчёт)

## Структура
- `questions/` — файлы вопросов q1.txt … q6.txt
- `answers/answers.txt` — сводка правильных ответов
- `report.md` — итоговый отчёт
